# AllScan Reimagined Beta 8.1.5.9

Beta 8.1.5.9 is a focused Net Bridge, Settings, and operator-workflow
maintenance release. It continues supporting official AllScan v1.02 through
v1.05 and remains a prerelease.

## Unified Net Bridge

- Completes the selectable DMR, YSF, P25, NXDN, and M17 Net Bridge workflow on
  shared private AllStar transport node 1999.
- Keeps DMR idle with no fixed/default talkgroup and never substitutes 4000 as
  a displayed destination.
- Keeps Zello and Net Bridge cards in their configured dashboard positions.
- Prevents overlapping high-frequency dashboard requests and avoids repeated
  M17 helper launches during status polling.
- Returns successful P25 and NXDN control actions immediately while status
  reconciliation continues through a bounded background refresh.
- Accepts YSF connection confirmation at the qualified gateway log level and
  synchronizes custom/imported reflector catalogs before activating YSF.
- Allows YSF reflector-list import and catalog status checks even when another
  Net Bridge mode is currently selected.
- Makes YSFHosts.txt upload binary-safe through the restricted container-to-host
  broker and validates the uploaded catalog before replacing the prior list.

## DMR security and easier setup

- Adds Settings fields for the TGIF Hotspot Security Key on both Standard DMR
  bridges and the DMR Net Bridge.
- Clearly distinguishes the Hotspot Security Key from the TGIF website password
  and the separate Static Talkgroups API token.
- Adds layman-friendly Help instructions for finding the key under the TGIF
  callsign menu, selecting an ESSID, checking the setup, and installing the
  bridge without terminal editing.
- Carries the broker, controllers, permissions, and catalog operations through
  normal install and reapply workflows so end users manage them in ASR.

## Dashboard, Favorites, and Settings fixes

- Expires transient Node Messages authentication notices instead of leaving a
  stale “Login required” message on an authenticated dashboard.
- Keeps Favorites management and import/export available from the Admin menu.
- Corrects Net Bridge mode forms so each mode shows only its own relevant
  controls rather than Standard-bridge or M17 fields from another mode.
- Separates Access-setting labels from their explanatory text.
- Stops mobile save bars from covering fields and content while scrolling.
- Preserves visible drag controls and consistent bridge-card ordering.

## Validation

- Validated DMR 67498, YSF US-Netoholics 67498, P25 6749, NXDN 6749, and
  M17-NET module A on virtual node 641890.
- DMR, YSF, P25, and M17 returned confirmed digital/reflector evidence. NXDN
  accepted destination 6749 and linked AllStar; the remote reflector did not
  provide the optional reachability response.
- Rechecked every Settings category at desktop and phone widths, including all
  five expanded Net Bridge mode forms.
- Passed source, controller, PHP, lint, build, final-archive, and virtual-node
  validation before publication.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed update. If the browser
updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
