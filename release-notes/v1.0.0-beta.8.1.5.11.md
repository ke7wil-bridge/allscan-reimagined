# AllScan Reimagined Beta 8.1.5.11

Beta 8.1.5.11 is a focused Docker bridge-diagnostics maintenance release. It
continues supporting official AllScan v1.02 through v1.05 and remains a
prerelease.

## Bridge Diagnostics

- Restores the read-only Asterisk link query used by Bridge Diagnostics on
  layered Docker nodes.
- Routes only the allowlisted `rpt lstats` request through ASR's existing
  host broker; the web container does not receive direct Asterisk or Docker
  access.
- Correctly reports connected Standard bridges such as URFWIL node 1001 and
  Zello node 1002 instead of `Cannot confirm`.
- Continues to label installed, unselected Net Bridge modes as inactive and
  the selected DMR Net Bridge as disconnected when it has no destination.

## Validation

- Passes the container broker, Asterisk reader, bridge dashboard, bridge UI,
  Zello, Talker identity, side-by-side installation, and deployment-source
  consistency checks.
- Confirms virtual node 641890 reports URFWIL 1001 and Zello 1002 as connected,
  while its DMR Net Bridge remains ready and disconnected with no destination.

Beta 8.1.5.11 does not install automatically.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed native update. If the
browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
