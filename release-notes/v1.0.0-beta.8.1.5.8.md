# AllScan Reimagined Beta 8.1.5.8

Beta 8.1.5.8 is a maintenance and security update. It does not include the
pending Net Bridge mode, ordering, diagnostics, or high-frequency polling work.

## AllScan v1.05 compatibility

- Adds an exact compatibility layer for official AllScan v1.05.
- Preserves the upstream v1.05 TouchGUI activity/statistics improvements,
  safer ASTDB handling, and PHP `glob()`-based Favorites discovery.
- Layered installations can pin the qualified upstream v1.05 commit
  `db1800c53515f9fddd079d1ec6968e686136d82b`.
- Continues supporting AllScan v1.02, v1.03, and v1.04.
- Nodes still on AllScan v1.04 need the supported terminal update command below
  for this one-time backend upgrade because David's official installer is
  interactive. Routine browser updates resume after stock AllScan reaches v1.05.

## Reliability fixes

- Marks a browser update as failed when its queued systemd worker never starts,
  instead of leaving the dialog at `Waiting to start...` indefinitely.
- Returns valid, actionable JSON when the shared AllScan SQLite database is
  unavailable or damaged, so Favorites failures no longer collapse into an
  unexplained response-parsing error.
- Warns in Node Messages when the root filesystem is at least 90% full or has
  less than 512 MiB free. This warning does not delete files or repair a full
  filesystem; the node operator must free space and verify database health.
- Talker cards now discard entries older than 24 hours.
- The Commands control now uses the same theme class as adjacent Node Controls.

## Critical PHP security update

- Layered Docker builds use PHP 8.3.36.
- Existing Docker nodes must rebuild and recreate the ASR web container from
  this release; a browser-only ASR update cannot replace the container's PHP
  base image. ASR warns when an older affected Docker PHP runtime remains active.
- Native ASL3 installs refresh installed vendor PHP packages and restart Apache
  before continuing when the detected upstream PHP release predates the fixed
  security baseline.
- Non-APT systems stop with the exact fixed-version requirement instead of
  silently continuing on an outdated PHP runtime.

## Supported update command

If the browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```

This prerelease passed final archive testing and virtual-node validation on
node 641890 before publication.
