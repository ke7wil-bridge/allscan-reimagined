# AllScan Reimagined v1.0.0 Beta 8.1.5.6

Beta 8.1.5.6 restores native updates after a packaging-only validation failure,
makes update reminders dismissible per release, and extends stale-tab cache
protection to layered Docker installations.

## Terminal installation or update

Use this command on nodes running an older ASR version that does not yet offer
browser-based updates. It also works as the supported terminal update path for
newer native installations:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```

## Native update correction

- Corrects the bridge Settings self-test so it locates the API inside the
  packaged installer layout.
- Runs the bridge Settings validation against both the staged payload and the
  exact compressed release archive before publication.
- Preserves the existing rollback behavior if any installation check fails.

## Update reminders

- Adds **Remind me with the next version** to the dashboard update notice.
- Remembers the dismissal only for the currently offered version, so the next
  release is still announced automatically.

## Browser freshness

- Sends no-store headers for the HTML entry point and runtime API in layered
  Docker installations.
- Keeps immutable caching for hashed JavaScript and CSS assets.

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved.
