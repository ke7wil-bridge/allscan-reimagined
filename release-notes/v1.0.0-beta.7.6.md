# AllScan Reimagined v1.0.0 Beta 7.6

Beta 7.6 makes DMR connected-client visibility node-wide instead of viewer-specific.

## Highlights

- DMR connected stations now come from the node's shared connected-client collector feed.
- A logged-in user's TGIF session no longer replaces the shared DMR station list.
- Public status consumers and different AllScan users now receive the same DMR connected-client state.
- Per-user TGIF sessions remain available for authentication and control actions.
