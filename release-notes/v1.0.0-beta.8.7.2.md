# AllScan Reimagined Beta 8.7.2

Beta 8.7.2 is a maintenance update to Beta 8.7.1, focused on bridge controls, dashboard reliability and container upgrade recovery.

## Changes — Bridges

- Use authoritative ASR talker events and improve EchoLink origin identification and duration handling; preserve the actual callsign and incoming protocol rather than treating a relay as a separate talker.
- Improve transport sampling compatibility and legacy M17 link evidence.
- Compact Standard Bridge Connect/Disconnect controls and optimize bridge-card widths for desktop dashboards.
- Improve Connected Clients and Recent Activity entry layout, including connection duration and CONN/DISC/TX labels.
- Support verified exact Zello usernames, including spaces, in moderation controls and preserve the 60-second Kick across rekeying.
- Use direct established transport evidence to distinguish a manually disconnected Standard Bridge from propagated network topology.

## Changes — AllStar

- Display explicitly configured Favorites descriptions in Connection Status while retaining the original node identity and protecting transport identities.
- Keep the last verified bridge activity time during transient incomplete status responses; prevent overlapping bridge refreshes and stabilize permission refresh handling without weakening authorization.

## Changes — General

- Clean up redundant CSS and JavaScript while preserving existing themes, layout and functionality.
- Correct narrow mobile Kicks & Bans action overflow and Favorites color-palette overflow.
- Handle abandoned provisioning broker responses without spurious systemd exit status 120.
- Include the pinned AllScan source in release packages for supported offline layered container rebuilds.
- Migrate release-managed host helpers during compatible Docker browser upgrades, with checksum verification, durable recovery and rollback of the previous helper and volume state.
- Support cold container startup with read-only runtime mounts before the host broker becomes available; keep delegated controls fail-closed until authorized access is available.

## Upgrade notes

- Existing Docker hosts running the original Beta 8.7/8.7.1 updater require the documented one-time administrator-approved host bootstrap before compatible browser upgrades can migrate their managed helpers. See `docs/container-browser-updates.md`. The normal browser updater does not install arbitrary host infrastructure changes.
- Retain rollback backups until live bridge and dashboard acceptance is complete.
- Independent audio gains and live PCM meters are not included.

## Installation / update

After publication, use the dashboard's software update option where available. For a first installation or terminal recovery, use:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
