# AllScan Reimagined Beta 8.4.2 — Release Candidate

**Status: Candidate pending qualification and publication.**

## Changes since Beta 8.4.1

- Detect and restore a missing privileged updater during integrity recovery from the authoritative installed release.
- Show connected clients for bridges supporting client listing, even when Ban is unavailable; keep Kick and Ban individually capability-gated.
- Use generic release descriptions and What's New text.

## Known limitation

Intermittent Asterisk voice-queue hang (GitHub #140) remains under observation; Asterisk package updates are separate.

## Installation / update

Use the ASR dashboard browser-based update workflow where available. If the updater is missing, the terminal recovery command is:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
