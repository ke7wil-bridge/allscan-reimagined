# AllScan Reimagined v1.0.0 Beta 8.1.5.1

Beta 8.1.5.1 is a focused dashboard, installer, and update reliability release.
It retains the AllScan v1.04 compatibility and bridge improvements from the
previous Beta 8.1 releases.

## Fixes

- Restores an administrator-only **Update ASR** entry in the dashboard menu.
- Favorites preview a selected custom color immediately while the picker is
  open, before the save round trip completes.
- A recovered CPU-temperature request clears its earlier transient failure
  notice from Node Messages.
- The staged ASR login page guards nullable AllScan form-helper arguments on
  PHP 8.1 and later, without modifying the stock `/allscan/` interface.
- Opening **Update ASR** performs a fresh release check instead of treating the
  prior daily server cache as current.
- A failed or in-progress live check no longer leaves an older available
  version displayed as though it were the latest release.
- First installation no longer prints alarming red systemd messages while
  checking for ASR reapply units that have not been created yet.

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved by the supported updater.
