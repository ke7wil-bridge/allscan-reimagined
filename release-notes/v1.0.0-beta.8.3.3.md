# AllScan Reimagined Beta 8.3.3

Beta 8.3.3 corrects fresh URF installation when Settings already contains a display-only URF card.

## Corrections

- Treat an explicit display-only URF card with no ownership record, managed markers, Asterisk block, or runtime directory as a fresh installation rather than legacy ownership recovery.
- Replace that one display-only card with the managed record after installation while preserving URF073, private node 1001, TGIF talkgroup 42450, and the DMR-only protocol selection.
- Continue to fail closed when managed ownership is partial, a runtime footprint exists, the saved private node conflicts, or duplicate reflector identities exist.
- Explicitly verify native URF setup on Debian 13 while retaining Debian 12 support.
- Preserve Beta 8.3.2 targeted URF client Disconnect and Ban behavior.

## Installation / update

Use the ASR dashboard's browser-based update workflow. Do not reinstall or alter an existing working URF runtime to apply this correction.
