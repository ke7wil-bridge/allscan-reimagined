# AllScan Reimagined Beta 8.6.1 — Release Candidate

**Release candidate only:** publication and production deployment require separate owner approval after the manual acceptance gates below pass.

## Changes — Bridge and link recovery

- Replace fixed-bridge raw DTMF recovery with structured app_rpt link commands.
- Detect and safely clear impossible bridge autopatch state instead of leaving a bridge keyed with a busy tone.
- Prevent failed autopatch state from appearing as digital bridge TX activity.
- Add optional required AllStar link recovery with bounded 30-second, 60-second, then five-minute retry backoff.
- Avoid duplicate recovery when Asterisk already owns a native permanent startup link.

## Changes — Persistent bridge activity and DMR

- Continuously monitor authenticated TGIF DMR sessions and retain ordered, bounded CONN/DISC transition events.
- Ingest the TGIF event journal directly into standard DMR Recent Activity, with event-ID deduplication and silent initial synchronization.
- Keep the obsolete periodic TGIF session polling timer disabled and make the persistent monitor survive integrity/reapply cycles.
- Align Standard ASR and ASRPlus Recent Activity; retain incoming protocol-matched TX evidence and Zello TX-only behavior.
- Preserve exact DMR station identity and avoid fabricating historical connection/disconnection events.
- Recent Activity labels are uppercase CONN, DISC, and TX. Thomas is no longer required to repeat CONN/DISC/TX testing; operator live checks and automated regression coverage have been completed on Netoholics node 674982.
- QSO One's in-app disconnect/session behavior is under separate investigation with its developer. ASR records the disconnect when TGIF reports the session transition; this external app behavior is not evidence of a collector defect.

## Changes — Connected Clients and Recent Activity

- Accept root-group-owned reflector paths without accepting other group or world write access.
- Exclude the local gateway by reading bounded host interface addresses inside the restricted collector.
- Record evidence-based incoming TX and authenticated client connect or disconnect activity.
- Show baseline observations for stations already connected when tracking starts without inventing historical connection times.
- Persist roster baselines across collector restarts so observations are not duplicated.
- Suppress DMR registration pseudo-transmissions and retain unidentified incoming-talker status.
- Keep Standard ASR and ASRPlus Recent Activity contracts aligned.

## Changes — AllStar dashboard and Favorites

- Open native AllStar bubble charts from the dashboard and improve chart layout, interaction, and test coverage.
- Restore Favorites manager controls, safe synchronization, and symmetric drag scrolling.
- Improve authentication recovery after idle network interruptions.

## Changes — Talker cards, identity and activity

- Preserve standalone DMR, YSF, P25, NXDN and M17 talker cards that carried legacy URF metadata during upgrade or reapply.
- Restore once any standalone cards an earlier Beta 8.6 reapply retired, while preserving deliberate later deletions.
- Keep genuine AllStar talkers visible instead of filtering them as digital relay echoes.
- Retain four identified Last Talkers after relay filtering and dashboard refresh.
- Merge only quick same-station re-keys while preserving separate transmissions.
- Resolve numeric DMR radio IDs through the trusted host callsign database.
- Keep outgoing bridge relay identity separate from incoming digital talkers.
- Retain five-protocol bridge activity attribution and idle-state expiry behavior.

## Changes — Administration and diagnostics

- Add guarded Admin Scheduling for native AllScan schedules and allowlisted systemd timers.
- Require admin and same-origin security checks, dry-run-first timer validation and fail-closed privileged execution.
- Restore the scheduler runner and exactly one ASR cron entry during reapply.
- Detect IAX2 stall warning patterns using host-local native logs and UTC container logs.
- Read native and container Asterisk logs incrementally with bounded, rotation-safe cursors.
- Remove the diagnostics harness default that implicitly contacted a live backup hub.

## Changes — Updates, installer and dashboard reliability

- Fall back from noexec or low-space temporary storage to an executable update staging directory under /opt.
- Improve updater preflight and job error reporting without accepting arbitrary paths or release sources.
- Bound dashboard authentication checks and retry after idle-network, online, visibility and focus recovery.
- Keep dashboard data hidden while authentication is uncertain and redirect only after authoritative session expiry.
- Preserve the Beta 8.6 native AllStar bubble chart and restored Favorites management controls.
- Add release-build guards that prevent retired URF runtime files from returning.
- Preserve stock AllScan v1.06 compatibility throughout installation and rollback.
- Keep packaged and installed version metadata synchronized for browser update checks.

## Upgrade notes

- `requiredAllStarLinks` is optional. Do not configure the same node there and in app_rpt `startup_macro`.
- Bridge recovery remains opt-in per Standard Bridge.
- Nodes that still run a URF reflector must migrate before installing this release.
