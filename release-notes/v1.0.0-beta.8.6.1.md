# AllScan Reimagined Beta 8.6.1 — Release Candidate

**Release candidate only:** publication and production deployment require separate owner approval after the manual acceptance gates below pass.

## Changes — Talker identity, AllStar and Johnny2 recovery

- Preserve standalone DMR, YSF, P25, NXDN and M17 talker cards that carried legacy URF metadata during upgrade or reapply.
- Restore once any standalone cards an earlier Beta 8.6 reapply retired, while preserving deliberate later deletions.
- Keep genuine AllStar talkers visible instead of filtering them as digital relay echoes.
- Retain four identified Last Talkers after relay filtering and dashboard refresh.
- Merge only quick same-station re-keys while preserving separate transmissions.
- Resolve numeric DMR radio IDs through the trusted host callsign database.

## Changes — Connected Clients and Recent Activity

- Accept root-group-owned reflector paths without accepting other group or world write access.
- Exclude the local gateway by reading bounded host interface addresses inside the restricted collector.
- Record evidence-based incoming TX and authenticated client connect or disconnect activity.
- Show a baseline observation for stations already connected when tracking starts without inventing a historical connection time.
- Persist roster baselines across collector restarts so observations are not duplicated.
- Suppress DMR registration pseudo-transmissions and retain unidentified incoming-talker status.
- Keep Standard ASR and ASRPlus Recent Activity contracts aligned.

## Changes — Administration and diagnostics

- Add guarded Admin Scheduling for native AllScan schedules and allowlisted systemd timers.
- Require admin and same-origin security checks, dry-run-first timer validation and fail-closed privileged execution.
- Restore the scheduler runner and exactly one ASR cron entry during reapply.
- Detect IAX2 stall warning patterns using host-local native logs and UTC container logs.
- Read native and container Asterisk logs incrementally with bounded, rotation-safe cursors.
- Remove the diagnostics harness default that implicitly contacted a live backup hub.

## Changes — Installer, updater and dashboard reliability

- Fall back from noexec or low-space temporary storage to an executable update staging directory under `/opt`.
- Improve updater preflight and job error reporting without accepting arbitrary paths or release sources.
- Bound dashboard authentication checks and retry after idle-network, online, visibility and focus recovery.
- Keep dashboard data hidden while authentication is uncertain and redirect only after authoritative session expiry.
- Preserve the Beta 8.6 native AllStar bubble chart and restored Favorites management controls.
