# AllScan Reimagined Beta 8.1.5.14

Beta 8.1.5.14 is a dashboard usability update. It continues supporting official
AllScan v1.02 through v1.05 and remains a prerelease.

## What changed

- Fixes Node Controls so the Commands button no longer covers Disconnect on
  desktop screens or when changing themes.
- Adds **What’s New** inside the existing **Update ASR** window. Changes are
  described in everyday language, appear once after each installed version,
  and can be reopened later without adding another main-menu item.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed native update. If the
browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
