# AllScan Reimagined Beta 8.4.1 — Release Candidate

**Status: Candidate pending qualification and publication.**

## Changes since Beta 8.4

- Fix standard bridge link detection and per-bridge disconnected/reconnect UI, including narrow mobile layouts.
- Use concise bridge card labels for configured digital bridges.
- Modularize the dashboard stylesheet while retaining cascade order and add visual regression qualification.

## Known limitation

Intermittent Asterisk voice-queue hang (GitHub #140) remains under observation; Asterisk package updates are separate.

## Installation / update

For supported customer-node updates, use the ASR dashboard browser-based update workflow after publication and approval. The terminal recovery command is:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
