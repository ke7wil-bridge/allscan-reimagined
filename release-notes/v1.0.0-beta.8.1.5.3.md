# AllScan Reimagined v1.0.0 Beta 8.1.5.3

Beta 8.1.5.3 is a focused Talkers-card repair release. It retains the complete
browser updater repair and all dashboard improvements from Beta 8.1.5.2.

## Fix

- Restores DMR callsigns to the main dashboard Talkers cards on Netoholics and
  other bridge-only ASR nodes.
- Promotes structured DMR, YSF, P25, NXDN, M17, and Zello bridge activity into
  the main Talkers feed even when no matching AllStar transport row is present.
- Shows the digital mode and bridge or destination context while preserving the
  existing AllStar talker behavior and avoiding duplicate current/history cards.

## Browser update from Beta 8.1.5.2

No terminal command is required on a node already running Beta 8.1.5.2. The
main dashboard will show **ASR update available: v1.0.0 Beta 8.1.5.3**. Select
**Update ASR**, then complete the browser preflight and confirmation steps.

Beta 8.1.5.2 is the release that repairs the browser updater's least-privilege
sudo policy. A node running an older version may still require the supported
one-time bootstrap below before future browser updates will work.

## Fresh install or updater repair

Run this command from an interactive terminal on the node:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved by the supported updater.
