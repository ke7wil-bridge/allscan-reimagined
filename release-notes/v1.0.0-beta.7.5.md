# AllScan Reimagined v1.0.0 Beta 7.5

Beta 7.5 promotes the bridge-client and TGIF authentication fixes validated on the Netoholics node.

## Highlights

- TGIF connected clients now use each AllScan user’s authenticated TGIF web session.
- Supports TGIF CAPTCHA login without persisting the user password.
- Uses the current TGIF Talk Group Control session token for connected DMR clients.
- Fixes the YSF reflector log path and restores linked-gateway display.
- Renders current YSF fallback gateway snapshots instead of suppressing them.
- Installs the per-user TGIF helper sudo permissions required by the ASR web API.

## Deployment

Build and install Beta 7.5 through the normal release package. Do not copy a source checkout directly over an installed release directory; the release package supplies the generated `payload/web` tree used by reapply/upgrade.
