# AllScan Reimagined v1.0.0 Beta 8.1.1

Beta 8.1.1 contains the bounded Asterisk Manager recovery introduced in Beta
8.1 and hardens layered/container installation reproducibility.

## Layered AllScan pinning

- `ALLSCAN_REPO_REF` now accepts an immutable upstream Git commit in addition
  to branch and tag names.
- Container recreation can therefore remain on the exact qualified AllScan
  backend instead of silently following a newer incompatible upstream release.
- Exact compatibility-layer enforcement remains unchanged: ASR still refuses
  to start against an unsupported AllScan backend.
