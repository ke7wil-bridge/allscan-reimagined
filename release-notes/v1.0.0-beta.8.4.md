# AllScan Reimagined Beta 8.4 — Release Candidate

**Status: Unpublished candidate.** Release and deployment require final review and explicit approval.

## Changes under qualification

- Improved bridge setup and diagnostics, including URF/DMR runtime error reporting and safer installation checks.
- Expanded bridge status, service health, watchdog, and post-reboot diagnostic coverage.
- Added a read-only Asterisk media-queue early-warning detector to the node diagnostics recorder; it never restarts Asterisk.
- Expanded regression coverage for mobile layout, bridge provisioning, installer rollback, and update workflow.

## Known limitation

Intermittent Asterisk voice-queue hang (GitHub #140) remains open for observation after the virtual-node upgrade to upstream app_rpt 3.10.8. That Asterisk package update is separate from the ASR frontend package.

## Installation / update

For supported customer-node updates, use the ASR dashboard browser-based update workflow after publication and approval. The supported terminal recovery command is retained for packaging validation and emergency recovery:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
