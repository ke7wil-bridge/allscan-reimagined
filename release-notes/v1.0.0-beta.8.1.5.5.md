# AllScan Reimagined v1.0.0 Beta 8.1.5.5

Beta 8.1.5.5 makes failed Net Bridge mode changes visible where they occur and
prevents a restored browser tab from quietly presenting an older ASR build as
the version currently installed on the node.

## Net Bridge diagnostics

- Keeps the exact mode-switch failure visible on the Net Bridge card after ASR
  safely returns the selector to the previous working mode.
- Labels installed services for unselected Net Bridge modes as intentionally
  inactive instead of reporting them as backend faults.
- Adds focused YSF guidance for exact catalog names, five-digit IDs, custom
  reflectors, and the evidence to collect after a failed activation.

## Browser version freshness

- Rechecks the installed ASR version when a tab regains focus, becomes visible,
  or is restored from browser history.
- Shows a clear **Refresh now** notice when the tab's JavaScript build differs
  from the version installed on the node.
- Reports a temporarily unavailable version during an initial API failure and
  retries instead of displaying a stale authoritative-looking version.
- Prevents caching of the HTML entry page and runtime API while retaining
  immutable caching for hashed JavaScript and CSS assets.

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved.
