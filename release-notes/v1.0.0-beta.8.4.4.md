# AllScan Reimagined Beta 8.4.4 — Maintenance Release

**Status: Local release candidate pending review, publication, and deployment approval.**

## Changes since Beta 8.4.3

- Strengthens installer staging checks and recovery on systems with restricted or undersized temporary filesystems.
- Safely creates the first stock AllScan administrator before mandatory-login policy is enabled on a fresh installation.
- Preserves appearance-setting permissions during installation restore.
- Expands Favorites ordering, guarded file editing, exact backups, protected restore, duplicate and membership validation, legacy migration, and selected-source recovery.
- Hardens Support and Feedback attachment handling and issue submission while retaining keyboard focus, mobile, and theme behavior.
- Shows complete, scrollable release notes in the update dialog.
- Packages read-only alert-state, Broadcastify, EchoLink, post-reboot, version-drift, configuration-export, and integrity diagnostics with isolated self-tests.

## Bridge compatibility

This maintenance release intentionally adds no new bridge provisioning, protocol,
status, talker, client-management, recovery, audio-gain, audio-meter, endpoint, or
URF behavior. It retains the bridge configuration formats, services, transports,
runtime directories, APIs, and Kick/Ban behavior published in Beta 8.4.3.

## Deferred work

- Unified and direct digital bridge development remains outside this release.
- ASR Plus three-hub monitoring changes and PR #186 saturation diagnostics remain pending their separate live validation.
- Live RF, audio, bridge-traffic, upgrade, rollback, and reboot acceptance must still be completed on representative nodes before deployment approval.

## Installation / update

Use the ASR dashboard browser-based update workflow where available. For first installs or terminal recovery, use:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
