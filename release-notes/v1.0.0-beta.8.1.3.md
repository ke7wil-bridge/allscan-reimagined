# AllScan Reimagined v1.0.0 Beta 8.1.3

Beta 8.1.3 is a focused reliability update for four user-reported dashboard
problems. It retains the AllScan v1.04 compatibility introduced in Beta 8.1.2.

## Fixes

- Custom command buttons now use a bounded request and report failures instead
  of leaving the dashboard window unresponsive.
- CPU temperature refresh failures no longer leave a stale temperature visible
  or pair a failure message with misleading hard-coded temperature data.
- Node Controls keep their compact geometry while resizing through intermediate
  window widths instead of stretching or splitting the controls.
- Reapply and integrity checks now install and restore the Favorites manager
  helper and its required permission rule, so Favorite color changes remain
  available after installation or repair.

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved by the supported updater.
