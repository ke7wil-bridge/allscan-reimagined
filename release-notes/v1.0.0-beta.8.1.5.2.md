# AllScan Reimagined v1.0.0 Beta 8.1.5.2

Beta 8.1.5.2 is a focused browser-updater repair release. It retains all
dashboard, Favorites, login-page, CPU-temperature, and installer improvements
from Beta 8.1.5.1.

## Fix

- Adds the five exact least-privilege sudo rules required by the administrator
  browser updater: check, preflight, queue, recovery, and job status.
- Extends the integrity service so an installation with missing updater rules
  automatically reapplies the correct policy.
- Adds a release-gate regression test that fails if the browser API operations,
  generated sudoers policy, and integrity checks fall out of sync.

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved by the supported updater.

## Install or update

Run this command from an interactive terminal on the node:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```

After Beta 8.1.5.2 is installed, future releases can be checked and installed
from **Admin → Update ASR** in the browser.
