# AllScan Reimagined Beta 8.2

Beta 8.2 consolidates the verified Netoholics live-activity recovery, improves URF bridge naming, and introduces RAM-aware Apache prefork limits.

If you're using AllScan Reimagined, Josh (KE7WIL) would appreciate a quick email letting him know you're running it. This helps track ASR adoption and support continued development: [ke7wil@gmail.com](mailto:ke7wil@gmail.com).

## Live bridge activity
- Preserve Apache write access to the runtime status directory during diagnostics sampling.
- Read native URF transmission events from the active runtime directory.
- Preserve proxied loopback M17/YSF/P25/NXDN client visibility.
- Avoid competing continuous AMI polling while retaining event-driven AllStar TX reporting.

## URF dashboard naming
- Derive the URF group heading from the configured reflector name.
- Normalize existing “Bridge” and “Multi-Mode Bridge” suffixes so the group heading displays one “Bridge” suffix.
- Keep the descriptive Connection Status label separate from the concise URF group heading.

## Memory protection
- Apply RAM-aware Apache prefork limits: 10 workers and 200 requests per child on systems below 1.8 GB RAM; 20 workers and 500 requests per child from 1.8 GB; 32 workers and 500 requests per child from 3.8 GB.
- Preserve larger administrator worker overrides only on systems with at least 1.8 GB RAM.
- Keep Asterisk protected from Apache prefork memory pressure on approximately 1 GB nodes.

## Installation / update

Run this command on the node:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
