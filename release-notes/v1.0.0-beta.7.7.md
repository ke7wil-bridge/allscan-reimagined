# AllScan Reimagined v1.0.0 Beta 7.7

Beta 7.7 restores reliable node-wide TGIF DMR connected-client visibility after the TGIF control-panel changes.

## Highlights

- Promotes the freshest authenticated TGIF user-session snapshot into the shared node-wide DMR connected-client feed.
- Keeps a fresh node-wide DMR feed authoritative for every AllScan viewer and public-status consumer.
- Uses per-user TGIF client state only as a fallback when no node-wide DMR feed exists.
- Preserves intentionally empty current DMR feeds instead of replacing them with viewer-specific state.
- Leaves DMR Net behavior unchanged.
- Fixes release archive ownership flags for GNU tar packaging.

## Live validation

Validated on the Netoholics/Thomas node: 18 authenticated TGIF sessions were collected into the shared ASR feed and deduplicated to 16 DMR stations in the public-status output.
