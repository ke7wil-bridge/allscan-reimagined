# AllScan Reimagined v1.0.0 Beta 8

Beta 8 is the active development prerelease built on the published Beta 7.5
baseline. The development line advances directly from Beta 7.5 to Beta 8.

## Connection Status reliability

- Bound Asterisk Manager connection, authentication, command, and response
  reads so an unhealthy AMI endpoint cannot stall a status request forever.
- Track failures independently for each configured node and temporarily open a
  circuit breaker after repeated failures.
- Preserve the most recent valid connection snapshot during a transient AMI
  failure rather than replacing it with a misleading empty result.
- Recover automatically after the breaker cooldown when Asterisk Manager is
  responsive again.

## Beta 8 development

Beta 8 also contains the in-progress bridge-management and dashboard work.
Existing manual/shared bridges remain outside ASR ownership unless they are
explicitly created as ASR-managed bridges.
