# AllScan Reimagined v1.0.0 Beta 8.1.5.4

Beta 8.1.5.4 completes the browser updater execution path and retains the DMR
and digital-bridge Talkers-card repair from Beta 8.1.5.3.

## Browser updater repair

- Installs the missing `allscan-reimagined-update@.service` worker used by the
  browser updater after **Update Now** is selected.
- Extends the integrity service to restore that worker automatically if it is
  ever missing.
- Adds installer and release-gate checks covering the worker file and its exact
  fixed updater command.

Beta 8.1.5.2 and Beta 8.1.5.3 can detect and preflight an update, but their
browser job cannot start when this worker is absent. Those installations need
the following one-time bootstrap repair. After Beta 8.1.5.4 is installed,
future releases can be installed through **Admin → Update ASR** in the browser.

## One-time update from Beta 8.1.5.2 or Beta 8.1.5.3

Run this command from an interactive terminal on the node:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```

## Included Talkers-card fix

- Restores DMR callsigns to the main dashboard Talkers cards on Netoholics and
  other bridge-only ASR nodes.
- Promotes structured digital bridge activity into the main Talkers feed even
  when no matching AllStar transport row is present.

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved.
