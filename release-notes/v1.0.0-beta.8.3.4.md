# AllScan Reimagined Beta 8.3.4

Beta 8.3.4 corrects the browser-driven URF installation workflow.

## Corrections

- Preserve the validated setup plan while an install-only TGIF hotspot security key is entered.
- Validate that key before confirmation and explain why Check Setup can pass without it.
- Convert synchronous browser failures, HTTP failures, and server validation failures into persistent visible errors.
- Avoid an install-only HTML rendering operation before the dmr-install request is dispatched.
- Preserve Beta 8.3.3 fresh URF ownership handling and Debian 13 support.

## Installation / update

Use the ASR dashboard's browser-based update workflow. Do not reinstall or alter an existing working URF runtime to apply this correction.

The repository's supported terminal recovery command is retained below for packaging validation and emergency recovery documentation. Do not use it for this upgrade; apply Beta 8.3.4 through the browser updater.

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
