# AllScan Reimagined Beta 8.1.5.12

Beta 8.1.5.12 is a native-node and Net Bridge maintenance release. It
continues supporting official AllScan v1.02 through v1.05 and remains a
prerelease.

## Fixes and operator safeguards

- Restores timed and permanent Global Ban storage on native nodes while
  retaining the existing container-mounted storage path on Docker nodes.
- Preserves recognized callsign suffixes such as `/R`, `/P`, `/M`, `/MM`, and
  `/QRP` on live and recent talker cards.
- Shows the exact TGIF device DMR ID/ESSID in Settings and clearly distinguishes
  the full one-time `TGIFSTG1` Static TG secret from TGIF's short Token ID.
- Documents TGIF protected destinations that cannot be selected through the
  Static TG API and explains when a separate ESSID is actually required.
- Rejects custom YSF entries that duplicate the installed reflector catalog
  before an operator can activate that mode.
- Adds a confirmed **Reset Net Bridge runtime** action. It disconnects the
  current digital session, restarts only the Net Bridge services, and restores
  private node 1999 without changing installed modes, credentials, other
  bridges, or dashboard settings.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed native update. If the
browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
