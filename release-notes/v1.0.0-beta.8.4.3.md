# AllScan Reimagined Beta 8.4.3 — Installer compatibility fix

**Status: Release candidate pending qualification and publication.**

## Changes since Beta 8.4.2

- New installations work on ASL3 systems even when the usual temporary folder is small or restricted.
- Installation files are prepared in a safer temporary location, with space and access checked before starting.
- If the temporary location is unsuitable, installation stops safely and leaves the existing ASR installation unchanged.

## Known limitations

- DMR TGIF Kick/Ban live acceptance remains open (#147).
- Release-wide upgrade, rollback, reboot and bridge qualification remains open (#129).

## Installation / update

Use the ASR dashboard browser-based update workflow where available. For first installs or terminal recovery, use:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
