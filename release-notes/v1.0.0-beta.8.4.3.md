# AllScan Reimagined Beta 8.4.3 — Installer compatibility fix

**Status: Release candidate pending qualification and publication.**

## Changes since Beta 8.4.2

- Fix fresh installs on ASL3 hosts whose `/tmp` is a 128-MiB `noexec` tmpfs.
- Stage the verified ASR archive and official AllScan installer under `/var/tmp` and check capacity and mount options there.
- Preserve the existing ASR installation and fail safely when staging resources are inadequate.

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
