# AllScan Reimagined Beta 8.3

Beta 8.3 improves bridge management, live status reliability, and mobile dashboard behavior.

If you're using AllScan Reimagined, Josh (KE7WIL) would appreciate a quick email letting him know you're running it. This helps track ASR adoption and support continued development: [ke7wil@gmail.com](mailto:ke7wil@gmail.com).

## URF reflector and bridge management
- Configure the reflector display name independently of the shared AllStar transport node.
- Prevent an older installation-specific default name from appearing as another reflector's identity. Existing installations may need to enter their preferred reflector name in Settings after updating.
- Improve browser-based URF runtime installation and repair, protocol selections, and retained settings.

## Live status and stability
- Avoid unsafe blocking EchoLink CLI commands in status collection and use bounded callsign lookup.
- Improve AMI status recovery, bridge activity timestamps, and status display after transient failures.
- Improve responsive Node Controls layout and preserve existing bridge behavior.

## Installation / update

Use the ASR dashboard's browser-based update workflow. Existing settings and bridge transport identities are preserved.

For terminal-based recovery only, the supported installer remains available:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
