# AllScan Reimagined v1.0.0 Beta 7.1

Beta 7.1 includes every change from Beta 7 plus a connected-client improvement
for locally owned digital reflectors.

## What Beta 7.1 adds

- Standard M17, P25, and NXDN Bridge cards can now show currently connected
  callsigns when the same system owns the reflector and a trustworthy current
  client list is available.
- The local bridge connection is excluded, so only other connected clients are
  shown and counted.
- Net Bridge cards remain excluded because a third-party reflector needs to
  provide its own trustworthy current-client source.
- Client information is refreshed more often so current counts do not briefly
  disappear between updates.
- Missing, outdated, incomplete, or conflicting information is treated as
  unavailable instead of being guessed.
- Installation and rollback checks were expanded for the new client source.

## Everything included from Beta 7

- The connection total now includes users connected through digital bridges.
  It shows a simple breakdown such as `3 ASL, 2 DMR, 3 YSF, 2 adjacent`, so the
  bridge users no longer need to be counted by hand.
- A connected Net Bridge is counted under its digital mode without also being
  counted a second time as a regular AllStar link.
- Bridge cards show only an incoming digital caller. A transmission that starts
  on the local node does not display a caller name on the bridge card. The name
  stays visible for the full transmission and clears when the transmission ends.
- Net Bridge cards no longer show an unnecessary Connected Clients box.
- Standard Bridges can optionally reconnect themselves if their local AllStar
  link drops. This does not control Net Bridges or interfere with an existing
  permanent-link setup.
- Reimagined Settings now supports as many as 16 bridge cards. If the limit is
  exceeded, ASR clearly refuses the save instead of silently losing cards.
- Bridge ID is now a dropdown for choosing DMR, YSF, Zello, P25, NXDN, or M17.
  The card title is still completely editable.
- The bridge panels are easier to recognize as expandable sections, with clearer
  plus and minus buttons and no input-like blue outline.
- YSF reflector lists can be imported from Reimagined Settings. ASR validates a
  new list before using it, shows its date and number of entries, and keeps the
  previous working list if an import is invalid.
- The rollback message is now large and obvious so the administrator knows to
  keep the page open. Completion is clearly confirmed before returning to the
  dashboard.
- Settings-save ownership, update survival, and rollback cleanup were strengthened
  so bridge settings do not require a manual ownership repair and older releases
  do not retain newer-version helpers.
- D-Star has been removed as an ASR bridge choice.
- P25, NXDN, and M17 now have Standard and Net Bridge setup foundations. They
  remain disabled unless the matching bridge software has been installed
  separately, its audio and connection path has been tested, and the destination
  owner has approved bridging. ASR will not claim that an unverified destination
  is connected.

## Installation

Open the Beta 7.1 release page and follow its installation instructions. The
normal update process checks the downloaded file before installation begins.

No automatic upgrade is performed.
