# AllScan Reimagined v1.0.0 Beta 8.1.4

Beta 8.1.4 improves digital-bridge setup and operator guidance while retaining
the reliability fixes and AllScan v1.04 compatibility from Beta 8.1.3.

## Improvements

- Unified Net Bridge setup now installs only the selected modes. A node can,
  for example, provide DMR and YSF without also provisioning P25, NXDN, and
  M17; the dashboard lists only the installed choices.
- Previously installed Net Bridge modes are preserved when another mode is
  added later.
- Bridge help now provides detailed field, preview, installation, verification,
  and troubleshooting guidance.
- The instructions explain how to change an ASR-managed Standard TGIF DMR
  talkgroup and distinguish that audio destination from the display-only TGIF
  Session Talkgroup.

## Compatibility

- AllScan v1.02, v1.03, and v1.04 remain supported.
- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved by the supported updater.
