# AllScan Reimagined Beta 8.1.5.15

Beta 8.1.5.15 adds node diagnostics focused on evidence, prevention, and conservative recovery.

- Adds a 48-hour flight recorder with one-minute RAM, swap, load, and process-memory samples.
- Adds dashboard warnings for low available RAM and rising swap use, plus detailed process snapshots when pressure is detected.
- Caps and compresses diagnostic history so it remains small, and keeps diagnostic files restricted to the node.
- Gives Asterisk stronger resource priority and never restarts it merely because memory or load is elevated.
- Adds conservative Apache worker limits and worker recycling without changing custom listener ports.
- Allows targeted recovery only after repeated measurements identify a supported offending service, with cooldown and post-recovery readiness checks.
- Records service readiness separately from confirmed end-to-end audio; a restarted bridge or service is never reported as restored audio without evidence.
- Integrates resource warnings with the existing dashboard warning flow and does not blame Apache, Cockpit, Allmon, USB, or another process without recorded evidence.
- Supports the same diagnostic design on native and Docker-based ASR installations while preserving node configuration, TGIF login state, bridge settings, and container volumes.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed native update. If the
browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
