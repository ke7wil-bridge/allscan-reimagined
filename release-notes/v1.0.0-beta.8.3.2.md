# AllScan Reimagined Beta 8.3.2

Beta 8.3.2 is a corrective release for URF DMR Connected Clients administration.

## Corrections

- Advertise Disconnect and Ban only after the backend proves that its DMR roster is readable and its administration state is safely writable.
- Make the layered browser-update deployment's shared TGIF runtime writable to the root-owned administration helper.
- Bind Disconnect and Ban to the selected current callsign and DMR ID; reject stale, mismatched, and ambiguous identities.
- Disconnect or ban only the selected client, preserve unrelated sessions and bans, and refresh the dashboard client list.
- Preserve Beta 8.3.1 URF ownership recovery, protocol visibility, transport node, talkgroup, credentials, and other bridge behavior.

## Installation / update

Use the ASR dashboard's browser-based update workflow. No URF reinstall or reflector-service restart is required.

For terminal-based recovery only, the supported installer remains available:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
