# AllScan Reimagined Beta 8.1.5.16

Beta 8.1.5.16 hardens URF provisioning and bridge-node ownership while preserving existing node services and credentials.

- Treats the configured and registered URF `bridgeNode` as authoritative during provisioning and reapplication.
- Detects and migrates a stale ASR-managed URF `rpt.conf` block to the authoritative node.
- Keeps Zello on its independently configured node and validates that URF and Zello never share a bridge node.
- Ensures both URF and Zello node mappings exist and makes repeated reprovisioning idempotent.
- Preserves existing external AllStar links, protocol identifiers, TGIF settings, dashboard activity, and diagnostic behavior.
- Restores mobile Node Controls behavior and corrects fast dashboard polling for the Netoholics layout.
- Improves public and private URF listener handling, protocol enablement, legacy bridge migration safeguards, and native runtime checks.
- Includes Docker Apache and AMI hardening for more reliable layered deployments.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed native update. If the
browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
