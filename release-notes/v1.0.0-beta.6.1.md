# AllScan Reimagined v1.0.0 Beta 6.1

Beta 6.1 is a focused prerelease update to the side-by-side Beta 6
architecture. Stock AllScan remains at `/allscan/` and ASR remains at `/asr/`.

## Changes

- Discovers every readable `/etc/allscan/favorites*.ini` list directly and
  displays the lists in ASR without requiring one symlink per file.
- Deduplicates matching Favorites basenames and prefers the preserved shared
  `/etc/allscan/` copy.
- Replaces the combined access behavior with separate, fully explained login
  choices for `/asr/` and `/allscan/`.
- Shows each interface's current access setting and preserves it when Enter is
  pressed during an upgrade.
- Reads installer answers from the interactive terminal without a short input
  timeout, including when the installer is launched through an SSH terminal.
- Corrects the Help & Instructions status legend to Green for Idle, Amber for
  Relay, and Red for TX Active.

## Install or upgrade

Run this from an interactive root terminal:

```bash
set -e

base="https://github.com/ke7wil-bridge/allscan-reimagined/releases/download/v1.0.0-beta.6.1"
pkg="/tmp/allscan-reimagined-1.0.0-beta.6.1.tar.gz"
checksum="/tmp/allscan-reimagined-1.0.0-beta.6.1.tar.gz.sha256"
stage="/tmp/asr-beta-6-1-install"

curl -fL "$base/$(basename "$pkg")" -o "$pkg"
curl -fL "$base/$(basename "$checksum")" -o "$checksum"
(cd /tmp && sha256sum -c "$(basename "$checksum")")

rm -rf "$stage"
mkdir -p "$stage"
tar -xzf "$pkg" -C "$stage"
cd "$stage/allscan-reimagined-1.0.0-beta.6.1"

php -l payload/server/asr-api.php
php payload/scripts/asr-favorites-discovery-self-test.php
php payload/scripts/asr-access-policy-self-test.php
python3 payload/scripts/asr-installer-prompts-self-test.py
python3 payload/scripts/asr-instructions-self-test.py
bash payload/scripts/asr-side-by-side-self-test.sh

bash ./install.sh
```

The release remains manual. It does not change a node, install itself, or
alter either interface's access policy without an explicit installer choice.
