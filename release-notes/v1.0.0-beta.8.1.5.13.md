# AllScan Reimagined Beta 8.1.5.13

Beta 8.1.5.13 is a bridge reliability, TGIF connected-client, and dashboard
maintenance release. It continues supporting official AllScan v1.02 through
v1.05 and remains a prerelease.

## Fixes and operator safeguards

- Changes TGIF website authentication from a browser-user session to one
  protected node-wide session, so every authorized viewer sees the same current
  connected-client roster and the login survives normal service restarts.
- Adds a dashboard warning and direct administrator sign-in link when TGIF
  requires another login. The DMR bridge can continue carrying audio while the
  roster login is unavailable.
- Rebuilds each TGIF roster from the current response instead of retaining stale
  clients, and excludes the node's own DMR bridge identity from both current and
  historical connected-client records.
- Monitors approved Standard Bridge service chains, reports an unhealthy or
  mismatched chain on the dashboard, and offers a confirmed repair that restarts
  only that bridge's allowlisted services.
- Preserves active custom Apache listener ports across ASR update and repair
  operations, preventing nodes that use ports such as `18080` from becoming
  unreachable after Apache restarts.
- Replaces managed friendly-name entries by node number and removes duplicates
  without overwriting unrelated local names.
- Keeps Node Controls inside their panel across narrow phones, enlarged mobile
  text, themes, and desktop layouts.
- Lets existing DMR Net Bridges that predate saved Static TG token metadata use
  their fixed protected token path without accepting arbitrary credential paths.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed native update. If the
browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
