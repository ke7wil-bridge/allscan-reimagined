# AllScan Reimagined v1.0.0 Beta 7.3

Beta 7.3 makes digital Bridge Cards clearer, safer to manage, and easier to
control.

## What's included in Beta 7.3

- DMR, YSF, Zello, P25, NXDN, and M17 Bridge Cards use clearer expandable
  settings.
- New cards begin as **New Digital Bridge**, while Digital Mode and Card Title
  remain separate.
- Each card shows only the settings, permissions, destinations, readiness
  details, advanced options, and client sources that apply to it.
- Before deleting a managed card, ASR shows what it will remove and what it
  will leave alone, then requires confirmation.
- ASR removes only bridge items it can prove it created. Existing, manual,
  shared, and display-only bridge installations remain untouched.
- An optional one-time startup summary can announce connected local Standard
  bridges after startup recovery. It is off by default and does not announce
  every link event.
- Dashboard warnings do not expose internal backend details.
- EchoLink callsign display is more dependable when the normal lookup is
  incomplete.
- Settings saves, ownership records, deletion retries, installation, integrity
  checks, and rollback have stronger safeguards.
- DMR Net Bridge operators can manually type a valid talkgroup number.
- YSF Net Bridge operators can manually type an exact reflector name or
  five-digit ID from the validated reflector catalog.
- The card's confirmed permission applies to every manually entered DMR or YSF
  destination.
- P25, NXDN, and M17 Net Bridges remain limited to saved approved destinations.
- Every Net Bridge destination box starts blank and clears after Connect or
  Disconnect. The active destination is shown separately on the card.
- DMR control verifies its live result through a protected status file before
  reporting success.
- Installation self-tests now work on systems that secure temporary folders
  with the `noexec` option.
- Integrity checks no longer expect an obsolete YSF refresh task.

Bridge software still needs to be installed separately. Beta 7.3 improves how
compatible bridges are displayed and controlled; it does not install a new
digital bridge system.

## Looking ahead to Beta 8

- A guided way to create new ASR-managed digital bridges.
- Ownership recorded from the beginning, so ASR knows exactly what it created.
- A replacement process when a bridge's mode or role changes.
- Existing manually installed bridges will remain separate and untouched.

Final Beta 8 features may change.

## Installation

checksum="${pkg}.sha256"

base="https://github.com/ke7wil-bridge/allscan-reimagined/releases/download/v1.0.0-beta.7.3"

curl -fL "$base/$(basename "$pkg")" -o "$pkg"
curl -fL "$base/$(basename "$checksum")" -o "$checksum"
(cd /tmp && sha256sum -c "$(basename "$checksum")")

tar -xzf "$pkg" -C "$stage"
