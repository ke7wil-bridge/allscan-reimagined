# AllScan Reimagined v1.0.0 Beta 8.1.2

Beta 8.1.2 adds exact compatibility with the official AllScan v1.04 backend
released on October 14, 2026.

## AllScan v1.04 compatibility

- Native and layered installations now recognize and apply an exact v1.04
  compatibility layer.
- All upstream v1.04 Favorites editing, ordering, and table-sorting changes
  remain intact because ASR continues to layer only its own integration files.
- AllScan v1.02 and v1.03 remain supported for existing installations.
- Layered installations can pin the qualified upstream v1.04 commit
  `1334df112dbfa9021316cbcbcc133c797e740533`.

## Included reliability fixes

- Retains the bounded Asterisk Manager recovery from Beta 8.1.
- Retains immutable upstream AllScan commit support from Beta 8.1.1.
