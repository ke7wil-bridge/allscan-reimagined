# AllScan Reimagined Beta 8.3.1

Beta 8.3.1 is a corrective release for URF ownership recovery, dashboard protocol visibility, and connection-management controls.

## Corrections

- Show only the URF protocols enabled in Settings. Existing configurations without an explicit protocol selection retain the legacy all-protocol behavior.
- Keep authorized Connection Status Disconnect and Ban actions visible above dashboard stacking contexts on desktop and mobile.
- Recover a missing URF ownership record only from a complete ASR-managed configuration, Asterisk, runtime-file, and service fingerprint; conflicting or external reflectors remain protected.
- Preserve the existing transport node, enabled protocols, ports, TGIF talkgroup, and secret during recovery. The URF-name example is now `URF123`.
- Preserve existing URF services, transport node 1001, credentials, talkgroups, runtime state, and protocol selections during the update.

## Installation / update

Use the ASR dashboard's browser-based update workflow. No bridge reinstall or URF repair is required.

For terminal-based recovery only, the supported installer remains available:

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
