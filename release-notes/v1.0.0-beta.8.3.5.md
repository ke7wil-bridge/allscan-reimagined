# AllScan Reimagined Beta 8.3.5 Release Candidate

Beta 8.3.5 is an unpublished validation candidate for the URF installation workflow.

## Corrections

- Prove that a validated Install Bridge click submits dmr-install with the hotspot key through an executable headless-browser regression test.
- Correlate browser, API, and privileged-helper stages with a non-secret request identifier.
- Audit dmr-install started, failed, and successful states; earlier releases recorded only successful completion.
- Automatically collect bounded, read-only evidence for missing runtime files, missing or failed services, inactive services, and recognizable TGIF authentication failures.
- Display supported API, helper, service, runtime, and request-submission diagnoses directly in the Bridge Setup Wizard.
- Preserve URF073, private node 1001, TGIF talkgroup 42450, and DMR-only configuration.

## Installation / update

This candidate must not be published or deployed until approved and validated. Customer-node upgrades must use the ASR dashboard's browser-based update workflow.

The repository's supported terminal recovery command is retained only for packaging validation and emergency recovery documentation; do not use it for this candidate upgrade.

curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
