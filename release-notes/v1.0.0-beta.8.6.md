# AllScan Reimagined Beta 8.6 — Release Candidate

**Release candidate:** Beta 8.6. Publication and production deployment are separate release steps.

## Changes — Talker cards and activity

- Fix Standard ASR M17 talker cards so the actual incoming reflector callsign stays visible without an incorrect numeric suffix or flicker between node and talker identities.
- Prevent outgoing USRP/AllStar relay activity from overwriting the incoming digital talker on M17 and other protocol cards.
- Preserve NXDN radio-ID-to-callsign resolution and show RELAY instead of misidentifying the AllStar node as an NXDN talker.
- Improve five-protocol bridge status, Last Talker and Recent Activity so entries reflect actual incoming bridge transmissions.
- Restore correct AllStar inbound-link indications on bridge status cards.

## Changes — AllStar and network visualization

- Add the interactive, theme-aware AllStarLink bubble chart to Standard ASR, with live topology, station details, zoom, pan and expand/collapse controls.
- Make clickable station descriptions in Connection Status consistently bold, with underline only on hover or keyboard focus.
- Improve bubble-chart framing, node-number placement and refresh stability to avoid clipped bubbles, overlapping labels and blinking.
- Add an Asterisk IAX2 stall detector to node diagnostics.

## Changes — Digital bridges

- Replace URF reflector support with Standard and Net Bridge operation; preserve retired URF configurations in a backup file.
- Restore direct DVSwitch/TGIF DMR Standard and Net Bridge provisioning, selected talkgroup routing and connected-client reporting.
- Add independent bridge audio gains and measured PCM meters in bridge Settings.
- Add bridge port-collision safeguards and more reliable bridge state reporting.

## Changes — Bridge controls and security

- Move Global Ban to its own helper and `global-bans.list` policy, automatically migrating existing bans.
- Apply Global Ban and Kick state to managed Zello containers.
- Add DMR exact-ID Kick enforcement checks and install native administration support for YSF, P25, NXDN and M17 public reflector ports.

## Changes — Appearance and general improvements

- Improve theme consistency across menus, buttons, Favorites and the mapping module.
- Preserve configured Favorites and node settings across updates and improve installation rollback safeguards.
- Support the current stock AllScan v1.06 backend without downgrading it.

## Bridge controls — known limitations and follow-up

- Beta 8.6 ships the current bridge controls as-is. Global Ban passed Doug’s Nov 20 live checks across modes, and Kick passed AllStar and EchoLink.
- Doug reported that Kick did **not** produce a confirmed disconnect in DMR, YSF, P25, NXDN, or M17 using QSO1 audible indications. QSO1 visual connection status may not reliably reflect ASR enforcement. Those modes are **not certified as live Kick-pass** in this release.
- Additional live enforcement verification and corrections will follow in a subsequent update under issue #134. Do not assume every digital Kick operation disconnects the remote client immediately; verify bridge media enforcement independently.

## Upgrade notes

- Nodes that still run a URF reflector must migrate to Standard or Net bridges before installing this release.
- Software outside ASR that reads `/run/urf-wil-config/urfd.blacklist` keeps working through a read-only compatibility link.
