# AllScan Reimagined Beta 8.6 — Release Candidate

**Release candidate:** Beta 8.6. Publication and production deployment are separate release steps.

## Beta 8.6 talker updates

- Preserve the Netoholics-accepted incoming M17 reflector callsign in Standard ASR talker cards.
- Remove numeric M17 callsign suffixes from displayed identity.
- Prevent outgoing USRP relay or generic AllStar keyed status from replacing incoming M17 talker identity.
- Preserve NXDN numeric radio-ID callsign resolution where a local ID directory is configured.
- Add regression coverage for M17 stream start, end, source priority and identity validation.
- Isolate bridge setup diagnostic tests from pre-existing host runtime files.

## Bridge integration baseline

The following changes are inherited from the Beta 8.5.1 bridge integration candidate; release validation and integration with current `main` remain required.

## Changes since Beta 8.5

- Removes URF reflector support completely. Saved URF reflector cards move to `retired-urf-bridges.json` after a configuration backup; no runtime data or credentials are deleted.
- Runs Standard and Net Bridge DMR on the direct DVSwitch/TGIF runtime. DMR Net Bridge provisioning works again and follows the selected talkgroup in both directions.
- Shows connected DMR clients on direct DMR bridge cards.
- Moves Global Ban to its own helper and the `global-bans.list` policy file. Existing bans migrate automatically.
- Managed Zello containers now receive Global Ban and Kick state.
- Kick verifies the selected DMR client by exact ID and waits for the relay to confirm the media is blocked.
- Kick/Ban for YSF, P25, NXDN and M17 public reflector ports is now installed and updated by ASR.
- Brings in the five-protocol bridge status collector: incoming-only Last Talker and Recent Activity, and a correct AllStar link indicator for inbound links.
- Adds independent bridge audio gains and measured PCM meters in bridge Settings.
- Adds bridge port-collision safeguards.
- Adds the Asterisk IAX2 stall detector to node diagnostics.

## Bridge controls — known limitations and follow-up

- Beta 8.6 ships the current bridge controls as-is. Global Ban passed Doug’s Nov 20 live checks across modes, and Kick passed AllStar and EchoLink.
- Doug reported that Kick did **not** produce a confirmed disconnect in DMR, YSF, P25, NXDN, or M17 using QSO1 audible indications. QSO1 visual connection status may not reliably reflect ASR enforcement. Those modes are **not certified as live Kick-pass** in this release.
- Additional live enforcement verification and corrections will follow in a subsequent update under issue #134. Do not assume every digital Kick operation disconnects the remote client immediately; verify bridge media enforcement independently.

## Upgrade notes

- Nodes that still run a URF reflector must migrate to Standard or Net bridges before installing this release.
- Software outside ASR that reads `/run/urf-wil-config/urfd.blacklist` keeps working through a read-only compatibility link.
