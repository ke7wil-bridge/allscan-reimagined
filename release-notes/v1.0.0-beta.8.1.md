# AllScan Reimagined v1.0.0 Beta 8.1

Beta 8.1 is a focused stability release for Connection Status and Asterisk
Manager recovery.

## Asterisk Manager recovery

- Retains the per-node circuit breaker introduced in Beta 8. A failed bounded
  XStat or SawStat request still stops normal status polling and preserves the
  last confirmed connection state instead of repeatedly loading Asterisk.
- Adds cautious same-process recovery after a 60-second cooldown. ASR requires
  three consecutive successful bounded XStat/SawStat results before clearing
  the breaker.
- Any failed recovery probe resets the success count and backs the next status
  probe off by 5 minutes, then 15 minutes, then a maximum of 60 minutes. An
  Asterisk restart still clears the breaker immediately when the boot identity
  changes.

This change repairs stale Connection Status and last-talker displays after a
transient AMI timeout without weakening the protection against an unhealthy
Asterisk process.

## Roadmap

D-Star bridge setup and integration now targets Beta 8.2. The planned RC.1
milestone remains after D-Star qualification.
