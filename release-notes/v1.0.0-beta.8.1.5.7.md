# AllScan Reimagined v1.0.0 Beta 8.1.5.7

Beta 8.1.5.7 is a maintenance release for bugs and regressions found during the
Beta 7.5-to-8.1 transition. D-Star bridge work is intentionally deferred to
Beta 8.2.

## Terminal installation or update

Use this command on nodes running an older ASR version that does not yet offer
browser-based updates. It also works as the supported terminal update path for
newer native installations:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```

## Native installation and Net Bridge switching

- Detects the active local Apache port when validating a native installation,
  including nodes whose AllScan web server listens on a nonstandard port such
  as 8080.
- Applies the detected local base URL to the PHP runtime, ASR configuration,
  authentication-status, and installed-page checks.
- Allows a DMR-to-YSF Net Bridge switch to continue when systemd reports that
  the already-stopped DMR worker is not loaded, while retaining rollback for
  actual mode-switch failures.

## Node Controls and Favorites

- Remembers the most recently selected Node Control action in the current
  browser, without changing the existing action order.
- Remembers the Permanent checkbox in the current browser after the operator
  changes it.
- Stops appending the internal "User description" badge to an edited Favorite.

## Bridge Settings display

- Gives Net Bridge setup controls consistent field sizing and sufficient select
  padding so labels such as "Legacy (no personal key)" are not clipped.
- Applies the correction to the supported AllScan v1.02, v1.03, and v1.04
  compatibility packages.

## Compatibility and regression coverage

- Existing accounts, Favorites, node settings, ASR settings, branding, and
  bridge configuration remain preserved.
- Installer loopback discovery, native Net Bridge switching, Node Control
  persistence, Favorite rendering, and all supported bridge Settings variants
  have dedicated regression checks.
