# AllScan Reimagined v1.0.0 Beta 6.4

Beta 6.4 focuses on accurate connection accounting, bridge talker display,
Settings-save ownership repair, and rollback safety.

## Install or upgrade

Run this complete block from an interactive root terminal:

```bash
set -euo pipefail

base="https://github.com/ke7wil-bridge/allscan-reimagined/releases/download/v1.0.0-beta.6.4"
pkg="/tmp/allscan-reimagined-1.0.0-beta.6.4.tar.gz"
checksum="${pkg}.sha256"
stage="$(mktemp -d /tmp/asr-beta-6-4-install.XXXXXX)"

curl -fL "$base/$(basename "$pkg")" -o "$pkg"
curl -fL "$base/$(basename "$checksum")" -o "$checksum"
(cd /tmp && sha256sum -c "$(basename "$checksum")")

tar -xzf "$pkg" -C "$stage"
cd "$stage/allscan-reimagined-1.0.0-beta.6.4"

php -l payload/server/asr-api.php
python3 payload/scripts/asr-rollback.py self-test
python3 payload/scripts/asr-bridge-control.py --self-test
python3 payload/scripts/asr-ysf-bridge-control.py --self-test
python3 payload/scripts/asr-protected-config-metadata.py --self-test
bash -n install.sh payload/scripts/asr-reapply.sh

bash ./install.sh
```

## Changes

- Includes certified current digital-bridge clients in the dashboard's total
  linked count, grouped by bridge mode alongside ASL and adjacent totals. Each
  actively connected Net Bridge contributes one additional link to its mode.
- Excludes recent-talker and fallback lists from the connected total and
  deduplicates repeated clients within a bridge instance.
- Shows an inbound bridge callsign only while that station is actively
  transmitting, including transmissions longer than ten seconds. Completed,
  outbound Relay, disconnected, and failed-refresh states display no caller.
- Removes the Connected Clients detail box from Net Bridge cards while keeping
  regular bridge detail boxes and the combined connection totals.
- Distinguishes configured local YSF Gateway identities from inbound callers so
  outbound traffic remains Relay instead of appearing as a remote source.
- Safely restores protected Settings-file ownership after atomic web saves,
  rejecting symlinks, hardlinks, unsafe file types, and detected replacement
  races.
- Preserves newer reapply helpers while restoring an older release and reports
  a bounded failure reason if rollback must restore the previous installation.
- Adds regression coverage for protected configuration metadata, bridge-count
  arithmetic, caller direction, and strict rollback archive validation.
- Keeps generated ASTDB aliases out of rollback safety backups while continuing
  to reject arbitrary symbolic links.

## Safety

- Stock `/allscan/` remains beside Reimagined `/asr/`.
- Updates remain manual; Beta 6.4 does not install itself automatically.
- Existing users, Favorites, databases, personal configuration, secrets, and
  uploaded branding remain protected by the installer and rollback workflow.
