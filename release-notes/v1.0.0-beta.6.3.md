# AllScan Reimagined v1.0.0 Beta 6.3

Beta 6.3 adds the first multi-mode Net Bridge expansion while carrying forward the installer and interface fixes prepared after Beta 6.1.

## Changes

- Adds a separate, configurable **YSF Net Bridge** card without replacing or retuning a fixed/home YSF bridge.
- Replaces the long YSF reflector selector with a plain box accepting an exact reflector name or five-digit ID; no dropdown or suggestion list remains.
- Adds persistent custom YSF reflectors configured once by name, ID, hostname/IP, and port; ASR merges them with the official list without modifying the updater-owned source file.
- Refreshes and validates the current public YSF hostfile during installation and daily afterward, retaining the previous catalog if the public source is unavailable.
- Confirms YSF link and unlink results from the dedicated Gateway log, then verifies the separate local AllStar link.
- Shows the current reflector after refresh and reports Source/TX, Relay, Idle, warnings, and recent caller data only from real cached evidence.
- Adds root-owned audit records with timestamp, user, bridge, previous destination, requested destination, and result.
- Keeps each YSF Net Bridge configuration-driven; node numbers, paths, services, ports, and reflector choices are not hard-coded for a particular system.
- Moves the Favorites-file selector to the top of the Favorites menu.
- Clarifies the release alert actions: **Update instructions (recommended)** and **Download archive (advanced)**.
- Makes the shared Favorites requirement explicit during installation and removes the misleading optional decline path.
- Hardens post-install loopback validation for HTTP/HTTPS nodes and avoids the temporary release-check cache blip.
- Adds a clear rollback warning and a **Rollback Completed** confirmation before returning to the dashboard.
- Prevents generated `astdb.txt` artifacts from blocking rollback safety backups.
- Adds drag-to-reorder plus accessible Up and Down controls for bridge cards; the saved order controls their dashboard order.
- Increases typography throughout Reimagined Settings, with clearer bridge-setup labels and help text while preserving responsive mobile layouts.

## YSF Net Bridge scope

ASR configures and controls a dedicated YSF Net Bridge card only after that isolated bridge instance exists. It does not install or remove the third-party YSFGateway, MMDVM Bridge, Analog Bridge, emulator, or AllStar configuration. When an administrator explicitly saves custom reflectors, ASR creates a separate root-owned merged catalog, points only that dedicated YSFGateway to it, and restarts the dedicated Gateway so the entries are immediately available. The updater-owned source list remains untouched. Netoholics node numbers, service names, paths, ports, and reflector entries remain local configuration rather than product defaults.

## Testing status

Local helper, installer rollback, frontend, responsive-layout, and production-build tests passed. Netoholics live installation, YSF connection/disconnection, public-catalog refresh, service recovery, and rollback to Beta 6.1 were also validated before publication.
