# AllScan Reimagined Beta 8.1.5.10

Beta 8.1.5.10 is a focused Net Bridge status maintenance release. It continues
supporting official AllScan v1.02 through v1.05 and remains a prerelease.

## Net Bridge Relay Status

- Keeps a disconnected DMR Net Bridge idle when local AllStar traffic is active.
- Requires a confirmed digital destination before outbound traffic can display
  the DMR Net Bridge as Relay.
- Keeps inbound DMR Source/TX status authoritative.
- Makes Connect and Disconnect follow the actual DMR destination instead of the
  permanent private node 1999 transport.
- Establishes the local private transport from the bridge side, preventing an
  adjacent network's unrelated node 1999 advertisement from blocking a Net
  Bridge reconnection after a mode change.
- Gives Docker-managed URF/TGIF sidecars the host's real upstream DNS resolver
  when they share Asterisk's network namespace, so TGIF can reconnect after a
  sidecar restart.

## Validation

- Covers disconnected DMR, connected DMR, inbound Source/TX, outbound Relay,
  and release-to-idle behavior in the dashboard regression gate.
- Rechecks DMR, YSF, P25, NXDN, and M17 Net Bridge controls and the existing
  AllStar, URFWIL, and Zello connections on virtual node 641890.

Beta 8.1.5.10 does not install automatically.

## Supported update command

Use **Admin → Update ASR** for a normal browser-managed native update. If the
browser updater cannot start, run:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
