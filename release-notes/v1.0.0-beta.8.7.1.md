# AllScan Reimagined Beta 8.7.1

Beta 8.7.1 is a maintenance update to Beta 8.7. It focuses on reliability, operator controls, and corrections to existing features.

## Changes — Bridges

- Reserve node 1999 for the Unified Net Bridge. New Standard Bridge configurations cannot claim this node; existing conflicting assignments are not silently renumbered.
- Preserve independent Standard Bridge transport assignments and reject ambiguous or shared transport nodes for manual controls.
- Allow manual disconnect of an eligible Standard Bridge without disconnecting other bridges or the Net Bridge. The saved hold pauses automatic recovery for that bridge.
- Preserve the manual hold across configuration repair, upgrades and restarts; an explicit, verified reconnect restores the normal recovery policy.
- Detect permanent Asterisk startup links that could override a manual hold. Report the conflict without changing unmanaged Asterisk configuration.
- Require Asterisk to confirm the requested link state before reporting success; a pending connection is not treated as a confirmed disconnect.
- Improve scoped automatic Standard Bridge recovery on supported Docker hosts while respecting manual holds and recovery preferences.
- Serialize bridge-control operations with configuration writers and maintenance operations to reduce conflicting changes.
- Correct false M17 qualification warnings by applying managed-audio qualification checks only where appropriate.
- Correct Zello connected-client counts so historical talkers are not counted as currently connected clients.

## Changes — AllStar

- Strengthen Global Ban enforcement across configured, authorized Netoholics hubs, including eligible AllStar web-transceiver connections.
- Route callsign bans requested through supported MasterHub controls into Global Ban, including AllStar and EchoLink callsign bans.
- Apply node-owner callsign bans to supported digital bridge and EchoLink controls when the owner can be resolved.
- Disconnect an already-connected banned EchoLink station and continue applying bans to other supported hubs and bridges even if an EchoLink reload is pending.
- Improve ban and unban delivery and reporting when a hub is unavailable or not provisioned.

## Changes — General

- Improve What's New section spacing and make section headings easier to distinguish from their change lists.
- Strengthen automated test isolation by rejecting duplicate or unverified QA guest network addresses.
- Add isolated qualification checks for bridge transport assignment, manual holds, independent recovery, installer upgrades and reboot persistence.

## Upgrade notes

- Existing Standard Bridge assignments using 1999 require operator review before migration. Do not renumber live transports without checking the associated configuration.
- Permanent Asterisk startup links and external controllers may reconnect a manually disconnected bridge independently of ASR. Resolve reported startup conflicts before relying on a manual hold.
- Global Ban enforcement depends on each hub's provisioning and each protocol's available administration controls. Direct remote-hub ASR bans remain local; an external reflector or TGIF entry without the required DMR ID may not be enforceable remotely.
- Independent audio gains and live PCM meters are not included in this maintenance release.

## Installation / update

After publication, use the dashboard's software update option where available. For a first installation or terminal recovery, use:

```bash
curl -fsSLo /tmp/asr-bootstrap.sh https://raw.githubusercontent.com/ke7wil-bridge/allscan-reimagined/main/bootstrap.sh && sudo bash /tmp/asr-bootstrap.sh
```
